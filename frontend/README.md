# AccMarket Frontend

Vue.js фронтенд для маркетплейса игровых аккаунтов AccMarket.

## Технологии

- **Vue.js 3** - прогрессивный JavaScript фреймворк
- **Vue Router** - официальный роутер для Vue.js
- **Pinia** - state management для Vue
- **Axios** - HTTP клиент для API запросов

## Установка и запуск

### Установка зависимостей

```bash
cd frontend
npm install
```

### Запуск в режиме разработки

```bash
npm run serve
```

Приложение будет доступно по адресу: http://localhost:3000

### Сборка для продакшена

```bash
npm run build
```

## API Endpoints

Фронтенд взаимодействует с бэкендом через следующие endpoints:

### Аутентификация
- `POST /api/v1/auth/register` - Регистрация
- `POST /api/v1/auth/login` - Вход
- `POST /api/v1/auth/logout` - Выход
- `POST /api/v1/auth/update-token` - Обновление токена

### Объявления
- `GET /api/v1/core` - Получить список объявлений
- `GET /api/v1/core/user/{userId}` - Объявления пользователя
- `POST /api/v1/core/make-advertisement` - Создать объявление
- `PATCH /api/v1/core/edit-advertisement` - Редактировать объявление
- `DELETE /api/v1/core` - Удалить объявление

### Администрирование
- `GET /api/v1/admin/roles/all-users` - Все пользователи
- `GET /api/v1/admin/roles/user` - Роли пользователя
- `PATCH /api/v1/admin/roles/update` - Обновить роли
- `POST /api/v1/admin/roles/assign-admin` - Назначить админа
- `POST /api/v1/admin/roles/assign-moderator` - Назначить модератора

## Конфигурация

### Proxy настройки

В `vue.config.js` настроен прокси для перенаправления API запросов на бэкенд:

```javascript
devServer: {
  port: 3000,
  proxy: {
    '/api': {
      target: 'http://localhost:8090',
      changeOrigin: true
    }
  }
}
```

### Переменные окружения

Создайте файл `.env.local` для локальных настроек:

```
VUE_APP_API_URL=http://localhost:8090/api/v1
```

Используется Pinia для управления состоянием:

- Методы для регистрации, входа и выхода
- Автоматическое сохранение в localStorage

## Troubleshooting

### Проблемы с CORS
Убедитесь, что бэкенд настроен для приема запросов с `http://localhost:3000`

### Ошибки 401
Проверьте, что токены сохраняются в localStorage и отправляются с запросами

### Проблемы с прокси
Убедитесь, что бэкенд запущен на порту 8090
