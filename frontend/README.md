# AccMarket Frontend

Vue.js фронтенд для маркетплейса аккаунтов AccMarket.

## Технологии

- **Vue 3** - прогрессивный JavaScript фреймворк
- **Vue Router** - официальный роутер для Vue.js
- **Pinia** - хранилище состояния для Vue
- **Axios** - HTTP клиент для API запросов
- **Vite** - быстрый инструмент сборки

## Установка

```bash
# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр production сборки
npm run preview
```

## Основные функции

### Аутентификация
- Регистрация пользователей
- Вход в систему
- Автоматическое обновление токенов
- Защищенные маршруты

### Объявления
- Просмотр списка объявлений
- Создание новых объявлений
- Редактирование своих объявлений
- Удаление объявлений
- Фильтрация и сортировка

### Профиль пользователя
- Просмотр информации профиля
- Управление своими объявлениями
- Просмотр ролей

### Баланс
- Просмотр текущего баланса
- Пополнение баланса
- Вывод средств

### Уведомления
- Просмотр всех уведомлений
- Отметка как прочитанные
- Реальное время обновления

### Админ-панель (только для администраторов)
- Управление пользователями
- Назначение ролей (админ, модератор)
- Просмотр статистики

### Модерация (для модераторов и администраторов)
- Проверка объявлений
- Одобрение/отклонение объявлений
- Указание причин отклонения

### Апелляции
- Создание апелляций на отклоненные объявления
- Рассмотрение апелляций (для администраторов)

## API Интеграция

Фронтенд взаимодействует с бэкендом через REST API на `http://localhost:8090/api/v1`.

Прокси настроен в `vite.config.js` для перенаправления запросов `/api` на бэкенд.

## Аутентификация

Приложение использует JWT токены:
- **Access Token** - для авторизации запросов
- **Refresh Token** - для обновления access токена

Токены хранятся в localStorage и автоматически добавляются к запросам через Axios interceptors.

## Роли пользователей

- **USER** - обычный пользователь
- **MODERATOR** - модератор (может проверять объявления)
- **ADMIN** - администратор (полный доступ)

## Разработка

### Требования
- Node.js 16+
- npm или yarn

### Запуск
1. Убедитесь, что бэкенд запущен на порту 8090
2. Установите зависимости: `npm install`
3. Запустите dev сервер: `npm run dev`
4. Откройте http://localhost:3000

### Сборка
```bash
npm run build
```

Собранные файлы будут в директории `dist/`.
